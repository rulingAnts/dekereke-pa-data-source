Phonology Assistant add-on

Your Dekereke database, live in Phonology Assistant

Add your Dekereke .xml as a data source once. Then edit in Dekereke, switch back to Phonology Assistant, and it reloads by itself — no re-import, no converter to re-run, no stale snapshot.

Download the installer Free and open source · source on GitHub

What it does

Phonology Assistant reads Toolbox, FieldWorks, Speech Analyzer and PAXML — but not Dekereke. The usual workaround is to export a snapshot and re-export every time the data changes.

This add-on removes that step. Phonology Assistant keeps pointing at your real Dekereke file and notices when it changes, so your phonology charts, searches and CV patterns always reflect what you just typed.

Using it

  1. Install, then start Phonology Assistant

    The installer finds Phonology Assistant on its own and adds an uninstall entry.

  2. File → New Project, then Add ▾ → “Dekereke Data Source…”

    Also available under Project Settings for a project you already have open.

  3. Confirm the column mapping

    Dekereke column names are yours, so nothing is hard-coded: the add-on reads the column names out of your own database and guesses. Adjust anything it got wrong, then click OK.

  4. That’s it — keep working in Dekereke

    Every time you save and switch back, Phonology Assistant refreshes itself.

Good to know

Your data is never touched

The Dekereke file is only ever read. Conversion happens on a copy in a private cache folder.

Any Dekereke database

Column inventories differ from project to project, and both English and Indonesian column names are recognised.

Change the mapping later

Hold Shift while the project loads to reopen the mapping dialog.

Every encoding in the wild

Older UTF-16 databases and current UTF-8 ones both load, with no setting to choose.

Requirements

  • Phonology Assistant 4.1.1 on Windows (the add-on installs into its AddOns folder)
  • A Dekereke phonology database — Dekereke is Rod Casali’s software, at casali.canil.ca
  • Administrator rights for the installer, since Phonology Assistant lives in Program Files. Prefer not to? Each release also ships a manual-install zip.

If something looks wrong

The add-on keeps a plain-text log of everything it does — every load, how many records were converted, and how many were skipped for having no phonetic form:

%LOCALAPPDATA%\PaDekereke\addon.log

That file is the first thing to attach to a bug report.
